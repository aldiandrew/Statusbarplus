# Statusbarplus

No-root Android 16 app that displays the current day in the status bar using a normal Android notification, following the same basic mechanism as DateBar.

- No Accessibility Service.
- No overlay.
- No root/Xposed.
- Day text is rendered into the notification small icon.
- Device locale controls the day name.
- The clock/text-color option has been removed.
- Android 13+ notification permission is requested normally.
- A lightweight alarm updates the icon at the next day.

Reference: DateBar - date in status bar by Omer Peri.
